## Почему Lo

Обычные плееры строят библиотеку вокруг альбомов и требуют трёх тапов, чтобы включить музыку. Lo строится вокруг **даты**: открыл — сразу видно, что добавилось вчера, неделю назад, месяц назад. Один тап — играет.

Внутри — один живой `ExoPlayer` на всё приложение. Пауза мгновенная, скорость и тон меняются на лету, эквалайзер не перезапускает трек.

## Возможности

### Библиотека
- Лента всех треков по дате добавления, sticky-группы **Сегодня / Вчера / На этой неделе / В этом месяце / Раньше**.
- Бейдж **NEW** и полоска «докуда дослушал» прямо в строке.
- **Инкрементальный скан:** сначала лёгкий запрос `_ID + DATE_MODIFIED`, полные метаданные читаются только для новых и изменённых файлов. Ничего не изменилось — интерфейс не перерисовывается.
- Автообновление через `ContentObserver` + досинк при возврате в приложение. Новые треки появляются сами, удалённые исчезают.
- Исключение системных папок: рингтоны, уведомления, записи, мессенджеры.
- Скрытие отдельных треков, показ скрытых по желанию.

### Поиск и фильтры
- Мгновенный поиск по названию, артисту, альбому и папке.
- Сортировки: дата добавления, дата изменения, имя, артист, альбом, длительность, прослушивания, последний запуск.
- Фильтры: избранное, папка, направление сортировки. Выбор запоминается.

### Звук
- **Скорость 0.5–3.0×** с шагом 0.05 и пресетами.
- **Тон ±12 полутонов**.
- **Pitch Lock** — ускоряешь, голос не писклявит; выключишь — эффект плёнки.
- **Эквалайзер на 10 полос** с перетаскиваемой кривой, предусилением и пресетами: Ровно, Бас, Тёплый, Голос, Рок, Подкаст.
- **Доп. громкость 0–200 %:** ниже 100 % — чистое затухание на выходе, выше — усиление с лимитером, чтобы не клиппило.
- Мгновенная пауза, seek ±10 с двойным тапом, запоминание позиции для треков длиннее 10 минут.
- Shuffle и повтор, таймер сна, очередь с удалением и переходом к любому треку.

### Организация
- Свои плейлисты с коллаж-обложкой.
- Умные подборки: **Свежее**, **Не слушал**, **Часто слушаю**, **Долгие**.
- Избранное с «Играть всё» и «Вперемешку».
- Инфо о треке: папка, формат, размер, длительность, число прослушиваний.
- Поделиться файлом через системное меню.

### Интерфейс
- Тёплый графит и янтарь, крупная антиква в заголовках, без неона и градиентного шума.
- Акцентный цвет подбирается из обложки текущего трека.
- Мини-плеер → полный экран свайпом вверх.
- **Масштаб интерфейса 80–135 %** — для тех, кому мелко или крупно.
- Тёмная тема, edge-to-edge, тактильный отклик.

### Фон и система
- `MediaSessionService` + foreground service: играет в фоне, не убивается системой.
- Нотификация с обложкой и управлением.
- Пауза при отключении наушников, кнопки гарнитуры, аудиофокус.
- **Виджет на домашний экран**: текущий трек и кнопки «назад / пауза / вперёд».

### Интеграции
- **Обновление из приложения:** Settings → «Проверить обновления» смотрит GitHub Releases и качает APK через системный загрузчик.
- **Экспорт и импорт плейлистов:** M3U8, через «Поделиться» и системный выбор файла. Импорт сопоставляет треки по пути, имени файла и названию.

## Что внутри

| Слой | Технология | Зачем |
|---|---|---|
| UI | Jetpack Compose, Material 3 | быстрые анимации, лёгкий APK |
| Медиа | Media3 / ExoPlayer + MediaSession | gapless, фоновое воспроизведение, системные контролы |
| Скорость и тон | `PlaybackParameters` (Sonic) | меняются без перезапуска трека |
| Эквалайзер | `DynamicsProcessing` (API 28+) | одинаково на всех устройствах, 10 полос |
| Библиотека | MediaStore | система сама индексирует файлы |
| Кэш и статистика | SQLite | мгновенный старт, плейлисты, избранное |
| Настройки | DataStore | без блокировок UI |
| Обложки | MediaMetadataRetriever + дисковый кэш | читаются лениво, повторно не парсятся |

Всё локально: нет сети, аккаунтов и аналитики. Треки не покидают телефон.

## Сборка

```bash
git clone https://github.com/oyenter37-sudo/lo.git
cd lo
gradle :app:assembleRelease
```

CI собирает APK при каждом пуше в `main` и публикует релиз на тег `v*`:

```bash
git tag v1.0.9 && git push origin v1.0.9
```

Подпись берётся из секретов: `LO_KEYSTORE_B64`, `LO_KEYSTORE_PASSWORD`, `LO_KEY_ALIAS`, `LO_KEY_PASSWORD`.
