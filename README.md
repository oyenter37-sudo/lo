# Lo

Быстрый музыкальный плеер для Android: вся музыка с телефона по дате, поиск, плейлисты, скорость, тон и 10-полосный эквалайзер.

## Что умеет

- **Библиотека по дате** — новые треки сверху, группы «Сегодня / Вчера / Неделя», бейдж прослушивания.
- **Автообновление** — `ContentObserver` на MediaStore плюс досинк при возврате в приложение: новые треки появляются сами, удалённые исчезают.
- **Поиск** по названию, артисту, альбому и папке — мгновенно, без сети.
- **Сортировки и фильтры** — дата, имя, артист, альбом, длительность, прослушивания, избранное, папка.
- **Скорость 0.5–3.0×** и **тон ±12 полутонов** через `PlaybackParameters` (Sonic): меняются на лету, без перезапуска трека.
- **Pitch Lock** — ускоряешь, голос остаётся естественным; выключишь — эффект плёнки.
- **10-полосный эквалайзер** (`DynamicsProcessing`, API 28+) с пресетами, предусилением и перетаскиваемой кривой.
- **Мгновенная пауза** — один живой `ExoPlayer`, граф не пересобирается.
- **Плейлисты** — свои и умные («Свежее», «Не слушал», «Часто слушаю», «Долгие»).
- **Избранное**, очередь, shuffle/repeat, таймер сна, запоминание позиции для длинных треков.
- **Фон** — `MediaSessionService`, нотификация, кнопки гарнитуры, пауза при отключении наушников.
- **Дизайн** — тёплый графит и янтарь, акцент подбирается из обложки, крупная типографика, без неона.

## Установка

1. Открой [Releases](https://github.com/oyenter37-sudo/lo/releases).
2. Скачай `app-release.apk`.
3. Разреши установку из неизвестных источников и установи.
4. При первом запуске дай доступ к музыке.

Обновления ставятся поверх: подпись одна и та же, данные сохраняются.

## Сборка

Собирается в GitHub Actions (`.github/workflows/build.yml`) на тег `v*` или вручную (`workflow_dispatch`).

```bash
gradle :app:assembleRelease
```

Подпись — из секретов `LO_KEYSTORE_B64`, `LO_KEYSTORE_PASSWORD`, `LO_KEY_ALIAS`, `LO_KEY_PASSWORD`.

## Стек

Kotlin 2.0, Jetpack Compose (Material 3), Media3/ExoPlayer, MediaStore, SQLite, DataStore. Без сети и аккаунтов: всё локально.
